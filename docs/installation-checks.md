# Проверка установки Windows

Установщик готовит exe и резервную копию до остановки службы, проверяет права
каталогов, сериализует параллельные установки через системный mutex. Успех
означает запуск службы, ответ API через named pipe и создание ярлыка «Пуск».
При ошибке обновления существующей установки восстанавливаются прежний exe,
конфигурация службы и её предыдущее состояние запуска. Ошибка отката сообщается
вместе с основной ошибкой. Настройки и OpenVPN при установке не удаляются.

Если первичная установка завершилась ошибкой, созданная регистрация остаётся
для повторной установки; служба останавливается. Установщик не удаляет
повреждённые записи SCM и не редактирует реестр вручную: требуется устранить
указанную причину, иногда перезагрузить Windows.

## Обязательная ручная проверка перед массовым распространением

Выполнять в отдельной чистой Windows VM, не на рабочем VPN:

1. Запустить релизный exe обычным пользователем, подтвердить UAC.
2. Проверить автоматический запуск службы от LocalSystem, ответ `/v1/info`,
   ярлык для всех пользователей и открытие окна без повышения прав.
3. Перезагрузить VM: служба запускается, окно может подключиться к API.
4. Повторно установить ту же версию, затем новую: настройки сохраняются,
   ярлык не дублируется, служба и API работают.
5. Отклонить UAC: действующая установка продолжает работать.
6. Запустить два установщика: второй сообщает о занятой установке.
7. Проверить отказ записи в Program Files: действующая служба не останавливается.
8. Подменить новый exe тестовым, не запускающим службу: установка возвращает
   ошибку и восстанавливает старый exe и работавшую службу.
9. Повторить с корпоративной защитой: не отключать её и не обходить политики ИБ.

Автотесты покрывают подготовку копий, очистку временных файлов при ошибке,
COM и сохранение ярлыка, ожидание API и таймаут. Они не заменяют этот VM-прогон.
